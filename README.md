# Portfólio — Ciência da Computação

## 👨‍💻 Sobre mim

Olá! Meu nome é **João Lucas de Lima Souza** e sou estudante de **Ciência da Computação na PUC-SP**.

Este repositório reúne alguns dos principais projetos desenvolvidos durante minha formação acadêmica, apresentando diferentes conhecimentos adquiridos ao longo do curso, incluindo desenvolvimento de software, programação orientada a objetos, desenvolvimento web, bancos de dados, algoritmos, arquitetura de computadores e desenvolvimento de sistemas.

## 🚀 Projetos

### 🔧 Sistema Magnautos

Sistema de gerenciamento desenvolvido para uma oficina automotiva, com foco na organização dos processos internos e no gerenciamento das informações do negócio.

**Tecnologias:** React, Node.js, Express e MongoDB.

🔗 [Acessar repositório](https://github.com/jlucasslima/sistema-magnautos)

---

### 🎟️ Workshop Inside REI

Sistema web desenvolvido para gerenciamento de eventos, permitindo o gerenciamento das informações dos eventos e o processo de venda de ingressos.

O projeto também possui integração com serviços externos para processamento de pagamentos.

**Tecnologias:** Node.js, JavaScript, MongoDB e Mercado Pago.

🔗 [Acessar repositório](https://github.com/jlucasslima/WorkShop-InsideREI26)

**Tecnologias:** C/C++.
